# Plantillas para nuevos cambios

Desde la adopción de Spec Kit, usar las plantillas oficiales instaladas:

- [Especificación](../.specify/templates/spec-template.md).
- [Plan](../.specify/templates/plan-template.md).
- [Tareas](../.specify/templates/tasks-template.md).
- [Checklist](../.specify/templates/checklist-template.md).

El [piloto de errores](001-control-errores/spec.md) muestra la adaptación al
gimnasio. La [guía local](../docs/spec-driven-development.md) explica las skills,
la constitución y la verificación.

Conservar IDs estables de requisitos y relacionarlos con tareas y evidencia.
Escribir los documentos del proyecto en español; los encabezados de las
plantillas oficiales pueden mantenerse para facilitar el flujo de las skills.
No modificar las plantillas oficiales para un único cambio.
