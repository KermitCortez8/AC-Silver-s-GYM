# Especificaciones

Se conserva únicamente [000-base-implementada](000-base-implementada/spec.md),
el inventario del código existente. Es contexto del proyecto, no una orden de
implementación ni una feature pendiente.

No hay features activas. Las nuevas especificaciones se crearán solo cuando
el usuario indique que quiere utilizar Spec Kit. El generador oficial asignará
el siguiente número libre, actualmente 001.

Los contratos funcionales están en [base/modulos](../base/modulos/README.md).
El flujo disponible se explica en la [guía](../guias/spec-driven.md).
