# Reglas por tema y rutas

Leer siempre [generales](general.md), [seguridad](seguridad.md) y
[pruebas](testing.md). Las demás se consultan según los patrones de
[settings.json](../settings.json) y las rutas que afectará la feature.

| Área | Regla |
| --- | --- |
| HTTP, ensamblaje y aplicación backend | [API](api.md). |
| Vue, Pinia y frontend | [Frontend](frontend.md). |
| Dominio, repositorios, SQL y Supabase | [Datos](datos.md). |
| Spec Kit, CI y Docker | [Automatización](automatizacion.md). |

Codex lee esas reglas al completar contexto, especificar, planificar y modificar
archivos. context.md registra cuáles aplican y las fuentes que se contrastaron.
No hay un comando propio de selección ni un segundo catálogo de módulos.
